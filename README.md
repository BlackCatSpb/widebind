# WideBind / EVA — Единая Вычислительная Архитектура

**Экспериментальная языковая архитектура без трансформерных слоёв.**

Без attention, без больших softmax-матриц, без KV-cache. Память — это
вектор (VSA-суперпозиция), а не матрица. Информация «скрещивается»
биллинейно в узком буферном пространстве и «разворачивается» обратно
через когнитивный mirror-слой с коллективной памятью экспертов.

```
  ┌───────────────────────────────────────────────────────────────┐
  │                     WideBind / EVA                            │
  │   VSA-память · Bind-скрещивание · Cognitive Mirror           │
  │   нет attention · нет килобайтных softmax-матриц · без KV     │
  └───────────────────────────────────────────────────────────────┘
```

## 1. Три идеи

### 1.1. Память — вектор, не матрица

Каждый слой держит один D-мерный вектор-суперпозицию на каждом масштабе
времени (VSA). В отличие от контекстной памяти трансформера (матрица
K×V с попарными оценками), здесь генерация любой длины не требует
хранения истории: содержимое «свёрнуто» в вектор и обновляется
рекуррентно.

### 1.2. Скрещивание размерностей — биллинейность, а не взвешивание

Вместо «смешивания всех пар токенов» — проекция D→K, покомпонентное
произведение u⊙v (с golden-ratio-сдвигами), несколько «окуляров»,
проекция обратно K→D. Два разных представления *взаимно проецируются*
друг в друга, а не выбираются сходимостью softmax.

### 1.3. Мета-познание

Три уровня самосознания:

- **L0 — веса** (быстро переобучаемые): W_proj, α, log_scale экспертов;
- **L1 — private memory:** нетронутое EMA-состояние каждого эксперта,
  записываемое только уверенными K-пространственными состояниями;
- **L2 — meta-gate:** ворота «открывать ли зеркало» — настройка,
  выполненная самой моделью (полезность, доверие, противоречия).

**Дезайн-слоган:** WideBind не «хранит и распространяет», а различает,
сворачивает и разворачивает.

## 3. Обзор потока данных

```
[token ids]
     ↓
[PartitionedEmbedding: sparse code → sigmoid-микс → basis ⊕ + RoPE]
     ↓
  n_layers × WideBindBlock  (каждый со state: mem, mu, conv)
     ↓
[SigmoidCodedHead: 32 бинарных бита (K=32, S=6)]
     ↓
logits по вокабуляру  (head_normalize=True → нормализованы)
```

Интерфейс стека:

```python
out, state, global_state = model(h, state, global_state=…)
```

- **state** — переносимый рекуррентный контекст (память каждого слоя:
  VSA-состояние, первый момент, контекст свёртки);
- **global_state** — кросс-слойное глобальное состояние (передаётся во
  все зеркала как сигнал `global`).

В обучении (teacher forcing) state передаётся между батчами непрерывно;
на синтаксических границах (EOS) и при смене потока мягко гасится
(умножается на 0.1).

## 4. Эмбеддинг

`PartitionedEmbedding` (`core/embedding.py`):

1. **Код токена:** sparse block code — ровно S=6 активных бит из K=32
   (combinadic-нумерация + фиксированный seed=42; C(32,6)=906192 ≥ vocab).
2. **Плотный микс:** `z = σ(codes @ M × 2)`, где M — K×K ортогонально
   инициализированная матрица; каждый бит влияет на все 32 сегмента
   (rank-экспансия, полный ранг).
3. **Базис:** внешнее произведение `z ⊗ basis`, где `basis` — K×d
   (xavier, gain 0.5) — каждый сегмент получает своё d-мерное
   подпространство.
4. **RoPE:** позиционное кодирование 0 параметров, θ=1e6 (Qwen3-стиль),
   linear scaling.

Ключевое свойство: D делится на K сегментов, каждый сегмент 1:1 совпадает
с группой mirror (32×d) — эмбеддинг и mirror работают на тех же
сегментах, что упрощает согласование прохода B.

## 5. Основной блок (WideBindBlock)

Каждый блок получает на вход скрытый вектор `h`, рекуррентные состояния
(`mem_state`, `mu_state`, `conv_state`), `global_state` и управляющие
параметры адаптивного контроллера (см. §9).

```
h_in
 ├─ [Pre-LN: RMSNorm]
 ├─ [Conv1d depthwise 48-tap, causal]        → ветвь A
 ├─ [Bind: D→K→D, spiral/trajectory]         → ветвь B
 ├─ [VSA Memory: 4 шкалы τ]                  → ветвь C
 ├─ [Cognitive Mirror: G экспертов]           → ветвь D
 ├─ [CollectiveConceptLayer (опц.)]
 ├─ [Variable Precision Memory (опц.)]
 ├─ [Spectral: DCT × λ_k]                    → ветвь E
 ├─ [GroupedMLP: SwiGLU]                     → ветвь F
 └─ residual:  h = h + (A + B + C + D + E + F)
```

Порядок ветвей фиксирован, чтобы потоки градиентов не конфликтовали.

### 5.1 Pre-LN и свёртка

- **Pre-LN:** RMSNorm с фиксированным единичным весом (не обучается).
- **Conv1d:** depthwise, kernel=48, groups=D, без bias, causal
  (контекст только из прошлого), инициализация kaiming-normal.
- Выход свёртки `conv_out` дополнительно кэшируется для branch-loss
  (см. §11).

### 5.2 Bind — скрещивание размерностей

Bind — не эмбеддинг, а способ «послойного скрещивания» скрытых
состояний. Режим задаётся `bind_twist_mode`:

| Режим | Класс | Идея |
|---|---|---|
| `off` | BottleneckBind | диагональное u⊙v (legacy) |
| `shift` | BottleneckBind | S золотых сдвигов билинейных произведений |
| `cascade` | BottleneckBind | каскад по числам Фибоначчи |
| `spiral` | SpiralBind | комплексные вращения (cos/sin) |
| `trajectory_spiral` | TrajectorySpiralBind | спираль + траектория hp |
| `trajectory_spiral` + manifold | TrajectoryManifoldBind | лучи переходов + Zeckendorf |

**Общее ядро spiral-семейства:**

```
hp = RMSNorm(W_proj(h) + b)                  # D → K
θ = exp(W_freq)·hp + W_phase                # вращающаяся фаза
u′ = u·cosθ − v·sinθ;  v′ = u·sinθ + v·cosθ  # комплексное вращение
out = Σ_s (u′ ⊙ v′) @ W_out                  # 2·dims·K → D
```

- Комплексные вращения задают фазовое пространство; активации получают
  интерференцию между каналами.
- Гибрид: `α·HRR(a,b) + (1−α)·(a⊙b)`; α растёт от 0.3 до 0.7 за
  5000 шагов (HRR — свёрточный ассоциативный буфер, вычисляется через FFT).
- `trajectory_spiral` хранит 2 прошлых hp (EMA 0.9/0.1) и смешивает
  их с текущим — bind видит «траекторию».
- **TrajectoryManifoldBind** добавляет манифолд переходов:
  кольцевой буфер 1024 переходов `T=unbind(hp_t, hp_{t−1})`;
  кластеры-«лучи» (центроиды, greedy), sigmoid-ворота чтения по
  косинусу (без softmax на весь буфер); затухание по весу
  Zeckendorf-представления возраста луча; `log_gain` — обучаемая
  температура ворот.

### 5.3 VSA-память

Основная память — **4 фиксированных временных масштаба** на слой:

```
decay = clamp( exp(-1/τ_s)·σ(h·w_d + b_d), 0.01, 1.0 )
i_gate = softplus(h·w_i + b_i + γ·‖pred_err‖)
mem_t  = decay_t ⊙ mem_{t−1} + i_gate_t·h_t
```

- **Запись (i_gate):** softplus-ворота по содержанию + surprisal-добавка
  (предсказательная ошибка зеркала);
- **Динамические ворота модуляции** `w_i_dyn` от K-представлений
  экспертов зеркала; **ворота чтения** `w_q_dyn`;
- **Структура чтения:** «лист» (внутричанковое) + «контекст»
  (кросс-чанки) + первый момент `mu` (центроид записей);
- **Вычисление:** параллельный prefix-scan с чанками по 32 позиции,
  лог-пространство в fp32 под AMP; двухуровневое склеивание чанков;
- **Сумма по масштабам:** веса `scale_w` (sigmoid, пер-масштаб);
- **Выход:** `mem_read` × `w_mem2v` (вклад памяти, см. §9).

Первая моментная память `mu` хранит «центр масс» записанного:

```
ma_chunk = (w_k_mu·(h ⊙ i_gate))  →  prefix-scan с тем же decay
mu_read = mu_all · w_q_mu  →  добавляется к mem_read через w_mem2v.
```

### 5.4 Когнитивный mirror

Слой «мета-познания»: G экспертов (32 в большой версии, 8 в Mini),
каждый спроецирован в собственный K-буфер.

**Иерархия размеров K по глубине (staircase):**

```
L0..L(n/3)     → k=8   (широкий)
L(n/3)..2n/3   → k=16  (средний)
глубже справа  → k=32  (узкий, точный)
```

**Процедура зеркала по шагам:**

1. `hp = W_proj·h_g` — проекция каждого сегмента в K-пространство;
2. Обязательный **биполярный позиционный код** `pos_id` — бинарные
   знакопеременные буферы (фиксированный seed);
3. **Медленные сигналы** временной природы:
   - `temp` — отклонение от центроида памяти,
   - `global` — отклонение от глобального состояния,
   - `pred` — ошибка самопрогноза (`α_t·hp_prev`); большие α — опора
     на прошлую память, малые — на текущее состояние;
   - `sym` — билинейное взаимодействие `hp ⊙ hp_prev`;
4. **Быстрые сигналы актуальности:**
   - `smooth` — разности между соседними кадрами (causal Conv 3);
   - `help` — коллективная выборка из приватных буферов (опц.);
5. **Нормализация и выбор:** EMA-нормы сигналов, веса `sigmoid(log_w)`
   обучаемы — их мера и есть «что для зеркала важнее»;
6. **Слияние:** взвешенная сумма → RMS-норма → добавление bias →
   `Δ = norm` → линейное отражение → tanh
   → **skip-линейная ветвь** (αskip — по слою, от 17 до 0.1);
   выход масштабируется `exp(log_scale)`;
7. **Ворота эксперта:**
   `g = σ(w_gate·|Δ| + b_gate + delta_gate + grad_mod + dvar_mod +
        + противоречия + meta_trust)`
   — зеркало открывается в точках максимальной интенсивности;
8. `usefulness`: конкурентный предсказатель (MLP k→k→1) — прогнозирует
   свою пользу, дисциплинирует эксперт в сторону специализации.

**Private Memory (при `private_mem=True`):**

- банк `_private_mem` (G×k фиксированных буферов) пишется уверенностью:
  `conf = σ(−‖Δ‖)` — преимущество у редких и уверенных состояний,
  задержка запуска 5000 шагов;
- cross-expert recall: sigmoid-attention (не softmax) q⊗keys → `help`;
- **противоречие**: если разница «мнение эксперта против коллективного»
  велика — гейт снижается (доверие перераспределяется);
- `meta_trust`: EMA-матрица доверия, штраф нестабильным экспертам;
- аналитические графы (concept_sim, behavior_div, dominance) доступны
  через `debug_mind()`.

### 5.5 Первый момент

Величина первого момента `mu` (см. 5.3) — «центр записи истории».
Совместно с VSA-памятью даёт две характеристики (центр и распределение),
что стабилизирует чтение дальнего контекста.

### 5.6 Коллективный концепт-слой

`CollectiveConceptLayer` — эмуляция «понятийных групп»:

- M: S=8 нормализованных центроидов в K-пространстве;
- **адаптивная зрелость:** пока `cv = стд(residual)/сред` не опустится
  ниже 1/λ в течение λ шагов подряд, слой не пишет (детектор новизны);
- запись уверенных состояний: комбинация новизны (d_min > birth_gap*0.2)
  и уверенности (conf > median);
- чтение: softmax с температурой `_temp` по центроидам × occupation-веса
  → линейная проекция `W_o` (ортогональная инициализация), ворота
  `sigmoid(U-kappa·(pen-θ))` и `sigmoid(C·(cos − thresh))` — выход
  гасится, пока модель неуверенна;
- интегрируется во все слои (по умолчанию `collective_layer_idx=None`)
  или только в один указанный слой.

### 5.7 Переменная точность

`variable_precision=True` включает `ExactSequenceMemory` — маленький
точный кэш последних шагов (внимание-подобный, но локальный), включаемый
порогом `precision = σ(precision_gate(h)) > precision_threshold (0.3)`.
Компенсирует VSA-память на коротких дистанциях, где нужна точная
выборка позиций.

### 5.8 Спектральный слой и MLP

- **Спектральный:** базис DCT (фиксирован) проецирует и умножает на
  обучаемый спектр `λ_k` (зависящий от глубины слоя и от текущей
  дифференциации `spectral_mod`); обратное прямое преобразование;
  эффект — выделение характерных частот.
- **MLP:** GroupedMLP — разделение D на G сегментов, каждый со своим
  SwiGLU и расширением 4×, `norm`-слой внутри; это основной потребитель
  параметров (~79% весов модели). Выход слоя умножается на `mlp_mod`
  (полезность экспертов) — эксперт «знает», где его влияние нужно.

## 6. Голова: SigmoidCodedHead

Попытка кодировать словарь как **32 маргинальных бинарных предсказаний**
вместо полного softmax-слоя (хотя всё равно нормализуется):

```
Кодовое пространство: K=32 бит, активных S=6, C(32,6)=906192 ≥ vocab
Каждый токен: ровно 6 из 32 битов (combinadic + фиксированный seed=42)

z_k    = ⟨h_k, readout_k⟩         # K сегментов h (32 групп → d)
T      = exp(log_temp) ≥ 0.1      # температура бита (маргинальная)
z̅      = z/T + bit_bias          # маргинальный логит бита
u_k    = logit(P(bit_k = 1))
logit  = u·codesᵀ + base + token_bias
if head_normalize: logits −= logsumexp(logits)   # нормированные лог-вер.

logprobs(target) = Σ актив. битов log σ(z̅) + Σ неактив. log(1−σ(z̅))
                   − logZ + token_bias[target]
```

- **token_bias** — |vocab| свободных скаляров: выучивает частотный приор;
- **readout** делится с эмбеддингом (`tie_readout=True`, общий параметр)
  или собственный (xavier);
- **head_normalize=True** даёт единый лог-вероятностный вектор (формой
  softmax), но без большой матрицы d×vocab.

Таким образом голова — это (после фиксации кода) отдельный 32-битовый LM,
возвращающий нормализованные логиты.

**Когнитивная голова (CognitiveCodedHead)** — расширение: добавляет
температурную модуляцию (уверенность), битовые приоры, social bias
(доверие-граф зеркал), кодовые сдвиги (token_shift_embed), token_bias.
Используется редко; активная голова — SigmoidCodedHead.

## 7. Λ_d иерархия

Все «магические» константы системы — пороги, интервалы, множители LR —
выводятся из одного числа λ_d:

```
λ_d — положительный корень уравнения  x^d = x^{d−1} + … + 1
λ₂ = φ ≈ 1.618;  λ₃ ≈ 1.839;  λ_d → 2 при d → ∞
```

| Свойство | Формула | d=3 (λ≈1.839) |
|---|---|---|
| exploration threshold | `λ⁻²` | 0.296 |
| differentiation threshold | `λ⁻⁴` | 0.087 |
| b_i (ворота записи, expl=0/1) | −(λ+λ⁻¹) / −λ⁻¹ | −2.38 / −0.54 |
| b_d (долгота памяти) | λ±1/λ | 2.38 / 1.29 |
| w_mem2v_scale | λ⁻¹…1 | 0.544…1.0 |
| EMA alpha | 1−λ⁻⁶ … 1−λ⁻⁸ | 0.974 … 0.992 |
| noise_scale | λ⁻⁸ … λ⁻⁶ | 7.6e-3 … 2.6e-2 |
| delta_var EMA | 1−λ⁻⁴ … 1−λ⁻⁸ | 0.913 … 0.992 |
| gate_lr_mult | λ²/(λ−1) | ≈4.02 |
| warmup_steps | F₁₀·λ | ≈101 |
| eval_interval | F₁₃ | 233 |
| save_interval | F₁₆ | 987 |
| max_decay_steps | F₁₈ | 2584 |
| log_scale_init_std | λ⁻⁴ | 0.087 |

Реализация: `core/lambda_utils.py` (`lambda_d`, `LambdaConfig`) и
`WideBindConfig.__post_init__` → `_apply_lambda_d()` (галочка
`lambda_d_enabled=True`).

## 8. Группы параметров и LR

Правило: **временная динамика (гейты, ворота, память) — быстро; веса
(превращающие функции) — медленно.**

| Группа | Множитель LR | Содержит |
|---|---|---|
| embed | λ⁻² ≈ 0.296× | эмбеддинг, readout, проекции |
| mlp | λ⁻¹ ≈ 0.544× | ядра MLP, bind W_proj, W_out (не-mirror) |
| default | 1.0× | conv, norm-векторы, голова, прочее |
| mirror | λ¹ ≈ 1.839× | mirror W_proj/W_out, α, log_scale, skip_alpha… |
| gate | λ¹ ≈ 1.839× | w_gate, b_gate, w_i, b_i, w_q, w_mem2v… |
| vsa | λ⁻² ≈ 0.296× | b_d, b_i, scale_w (память-параметры) |

Каждая роль имеет симметричную пару `…_wd` (weight_decay=cfg.weight_decay
для 2D-параметров) или `…_wd=0` (bias и 1D-векторы, на которые decay не
распространяется).

Поведение legacy: `lambda_lr_hierarchy=False` — три роли:
base (1×), gate (×gate_lr_mult≈4.02), vsa (×vsa_b_lr_mult=0.1).

## 9. AdaptiveController

«Наблюдающий контроллер»: из статистик зеркал всех слоёв (|mirror| и
var(log_scale)) выводит актуальные параметры динамики:

```
expl = min(1,  |mirror| / λ⁻² )      # активность коррекции
diff = min(1,  var(log_scale)/λ⁻⁴ )  # специализация каналов
```

Далее рассчитываются **per-layer** (и глобальные версии для общих
настроек):

- `b_d` — расширение/сужение временного окна памяти (expl) с
  lerp-сглаживанием (`vsa_b_d_smooth=0.999`);
- `b_i` — ворота записи, детерминированные от τ:
  `i_target = min(1, 5.83/τ); b_i = softplus⁻¹(i_target) + base`,
  floor −6 (чтобы i_gate ≥ 0.0025);
- `w_mem2v`, `ema_alpha`, `noise_scale` — от `diff`;
- `tanh_bias_mod = 1 + 0.296·expl` (асимметрия зеркала в эврику);
- `spectral_mod = 1 ± 0.087·(diff−0.5)·2` (контраст спектра);
- `pred_scale_mod` — по-экспертная коррекция временного обучения.

Так система не гоняет «зашитые» константы, а сама подстраивает окна
памяти под степень зрелости зеркал.

## 10. MirrorLR-планировщик

Counter-циклический планировщик вместо cosine decay:

```
mult = (var_ratio × α_ratio × gate_ratio)^(1/3) · mag_factor · loss_lr_factor
```

- каждую эпоху по EMA собираются: var(log_scale), mean|1−α|, var(gates)
  и |mirror| (по всем слоям);
- ratio = текущая/EMA; если рост (компонент вырос) — LR снижается,
  если спад — растёт (геометрическое среднее трёх);
- `mag_factor` — противовес большого |mirror| (балансировка);
- `loss_lr_factor`: улучшение val → ×1.05; регресс ухудшение
  (val_loss > EMA× (1+λ⁻⁴)) → ×0.5 (плато-детекция);
- первые ~150 шагов: warmup с alpha-оверрайд зеркала (α→1) и
  температурой usefulness (T 2.0→0.5) — прогрев без шума.

## 11. Функции потерь

`Stack.compute_losses(h, targets, ...)` возвращает пару:
`ce_loss` (NLL), и `aux_dict` — словарь raw-значений aux-потерь
(веса применяются в сборке градиентов вне стека).

### Основная потеря

- **ce** — Negative log-likelihood через `head.log_probs_for_target`;
  при `head_normalize=False` — маргинальные логиты без нормировки.

### Вспомогательные (aux)

| Имя | Вес (deflt) | Формула/смысл |
|---|---|---|
| `pred` | 0.01 | ошибка предсказания α (hp_pred−hp), учит α-векторы |
| `pred_w` | 0.01 | ортогональность матрицы предсказания pred_w |
| `gate_l1` | 0.0001 | разреженность ворот expert'ов: mean(gate) |
| `reinforce` | 0.001 | soft-цель usefulness: MSE(u, gate) |
| `balance` | 0.026 | HHI-выравнивание usage экспертов (низкий rank) |
| `diversity` | 0.001 | деккорреляция групп MLP: ‖cov(y)−I‖² |
| `nuc` | 1e-5 | стохастическая ядерная норма W_bind: 𝔼‖Wv‖ |
| `orth` | 1e-4 (0=выкл.) | ортонормализация столбцов W_bind: ‖ŴᵀŴ−I‖² |
| `w_m2v` | 0.001 | иерархия вклада памяти по τ слоёв |
| `branch` | 0 (по умолч.) | равенство лог-дисперсий ветвей (conv/bind/mirror) |
| `div` | 50 | разнобразие log_scale: −(var(σ(ls),по экспертам) + √(d/G)·var(σ(ls),по каналам)) |
| `gate_repulse` | 0.3 | поднятие дисперсии gates (−var(gate_usage)) |
| `alpha_novelty` | 0.05 | разнообразие α по экспертам (var(α)) |
| `ranking` | 0.01 | согласованность ранга: высокий ls ↔ высокий usage |
| `decorr` | 0.01 | попарная ортогонализация сигналов зеркала |
| `signal_ent` | 0.01 | энтропия весов сигналов (анти-равенство) |
| `ls_reg` | 0.01 | L2 на log_scale выше 2.3 (анти-взрыв) |

Формулы ключевых:

```python
branch:   Σ_пар (log var(‖conv‖) − log var(‖other‖))²
ranking:  Σ relu(−(ls_i−ls_j)) · (gate_usage_i > gate_usage_j)
div:      −(var_G(σ(ls)) + √(d/G)·var_k(σ(ls)))
ls_reg:   mean(max(0, ls − 2.3)²)
```

## 12. Градиентная механика

Тренировка описана в `scripts/train.py` и каноническом ноутбуке:

1. **forward** (fp32/optional AMP) → `ce_loss, aux_dict`;
2. **CE-градиенты**: полный `torch.autograd.grad` (retain);
3. **Спектральное выравнивание** для Aligned aux:
   `scale = clip(cos_sim(g_CE, g_aux), 0, 10) · ‖g_CE‖/‖g_aux‖` —
   вся вспомогательная масса никогда не доминирует над CE-градиентом;
4. **Bypass-потери** (div/gate_repulse/alpha_novelty/ranking) —
   прибавляются в градиент БЕЗ масштабирования (сильный контроллер);
5. **Phase-ratio** per-слой: `ratio = ‖g_mirror‖/‖g_base‖` →
   `irm = sigmoid((ratio−EMA)/std)` → умножается на все параметры
   зеркала слоя (0.2×…2.0×) — «развитие фазы»;
6. **grad_clip** по норме параметров модели 0.5;
7. **AdamW** (β=(0.9,0.95)), lr из групп (§8) + MirrorLR (§10).

Такая архитектура градиента и есть механизм «фазы»: сначала
управляющие элементы (гейты/память) насыщаются быстрыми LR,
затем весовые параметры раскрываются в открытые ворота.

## 13. Инференс-интерфейс

```python
from core import LiveInference, MirrorMonitor

live = LiveInference(model, cfg)     # обвязка с состояниями
live.think(5)                        # «самодиалог» без внешнего входа
out  = live.respond(h_emb)            # подача эмбеддингов
tokens = live.generate(prompt_ids, 100, think_steps=0)

monitor = live.monitor
summary = monitor.summary(50)         # последние 50 шагов
```

**MirrorMonitor.trace** записывает в историю:
- `expert_gates` (n_layers × G), `mirror_mag`, `log_scale_mean/std`,
- `i_gate` (softplus(mean·w_i + b_i)) — фактическая скорость записи,
- `tau = exp(b_d)`, `exploration`, `global_state_norm`,
- rolling-сводка `summary(window)` — для анализа диалога.

Для big-моделей на инференсе памяти малы (~1 GB), т.к. глубинные
состояния — векторы, не матрицы.

меняться; чекпоинты совместимы между версиями только при строгой
миграции state_dict (`migrate_bind_state_dict` в bind.py).
