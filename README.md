# WideBind Main: Архитектурный обзор

**~255M параметров (default конфиг: D=4096, L=32, G=32), SwiGLU MLP, BottleneckBind (shift, S=4).**
Трёхслойный дифференцируемый аппарат саморефлексии:
Знание (L0) → Мета-знание (L1) → Арбитр (L2).

Гибридная языковая модель без transformer-слоёв: ни softmax attention, ни QKV, ни KV-cache, ни ReLU.
Вся архитектура — композиция дифференцируемых резервуаров. Данные (токены) проходят путь:

token → PartitionedEmbedding (разреженный 6/32-код → плотное смешивание → RoPE)
     → 32 блока WideBindBlock, каждый:
        Pre-LN RMSNorm → Depthwise Conv1d (k=48, groups=D) → RoPE
        → BottleneckBind (D→K↔K→D, билинейное скрещивание со сдвигами)
        → VSA Memory (4-масштабная суперпозиция с learnable τ)
        → GroupedCognitiveMirror (32 эксперта × 32 слоя, k=8/16/32 по глубине)
        → Collective Concept Layer (пер-слойный банк концептов, зрелость-гейт майнинга)
        → DCT Spectral (частотная фильтрация)
        → GroupedMLP (32 группы × expand=4, SwiGLU)
     → Final RMSNorm → PartitionedHead → logits

## 1. Философия и мотивация

### 1.1 Проблема современных LLM

Трансформер, MoE, RWKV и Mamba обладают общим фундаментальным ограничением: у них нет внутренней
модели собственного знания. Трансформер — это attention между токенами; модель не знает, что она знает.
В MoE gate выбирает экспертов, но эксперты не общаются между собой — нет коллективной памяти.
Символьные надстройки (EVA, Reflexion) работают через LLM-вызовы и не дифференцируемы.

### 1.2 Трёхслойная архитектура саморефлексии

| Слой | Название | Сущность | Пластичность |
|------|----------|----------|-------------|
| L0 | Знание | W_proj, alpha_diag, MLP | **Опасна** — правка весов разрушает знания |
| L1 | Мета-знание | Private Memory Bank (EMA уверенных K-space состояний) | **Безопасна** — отношение к фактам, не факты |
| L2 | Арбитр | K-Space Gate (несколько компонент) | Самонастраивается |

Принцип: модель знает (L0), знает, что она знает (L1), и решает, кому верить (L2).
Все три слоя — одна дифференцируемая функция: градиент течёт через всё одновременно, но с разной
скоростью и разным уровнем риска.

**Важно:** L1 (Private Memory Bank) — опциональный модуль. В default конфиге `private_mem=False`,
и модель работает в двухслойном режиме (L0 → L2). Все модули ниже описаны полностью, но секции
с пометкой «только при private_mem» активируются флагом.

### 1.3 Что это даёт

1. **Безопасная пластичность** — L1 можно менять без риска для L0.
2. **Коллективный разум** — cross-expert чтение между экспертами (при private_mem).
3. **Детекция противоречий** — высокое сходство концепций при сильном расхождении поведения = противоречие.
4. **Социальная динамика** — trust_matrix, dominance, isolation, social_pressure (при private_mem).

## 2. Partitioned Embedding — разреженные блочные коды

### 2.1 Механизм

Входные токены (V=cfg.vocab: 50000 по умолчанию, 65536 с расширенным токенизатором) кодируются
не проекцией, а **адресацией** через разреженный блочный код (6-out-of-32). Каждый токен получает
детерминированный бинарный код с ровно 6 единицами из 32 бит
(K=32), построенный комбинаторной системой счисления (combinadic): C(32,6)=906192 ≥ 50000, каждый бит
представлен равномерно (≈9375 токенов на бит). Код сохраняется как буфер (не параметры).

Basis — матрица сегментов K×d (32×128=4096), инициализируется Xavier gain=0.5. Вектор токена —
сумма сегментов базиса, соответствующих активным битам кода.

### 2.2 Плотное смешивание (mix-матрица)

Разреженный код не используется напрямую: он пропускается через learnable ортогонально инициализированную
mix-матрицу K×K с масштабом 2.0 и сигмоидой. После этого каждый бит влияет на все 32 сегмента
(rank expansion), и коэффициенты становятся плотными. Смешанные коды домножаются на сегменты базиса
и собираются в D-мерный вектор.

После смешивания применяется **RoPE** (Rotary Position Embedding, theta=1e6, линейный scaling 1.0).

### 2.3 Преимущества

- Сегменты базиса выровнены 1:1 с mirror-группами (32×128 в Main).
- Разреженный код стартует как адресация (6/32), но mix-матрица даёт плотное влияние всех сегментов —
  «sparse-вычислений» после mix нет, работает всё K-пространство.
- Детерминированность: одинаковые токены → одинаковые стартовые коды.
- Параметры: basis 4096 + mix 1024 ≈ 5,120 (экономно относительно плотной таблицы 50000×4096).

## 3. Partitioned Head — сегментированный выход

Обратная операция к Partitioned Embedding. Состояние h разбивается на те же K=32 сегмента по d=128;
каждый сегмент скалярно сравнивается со своим readout-вектором, после чего баллы агрегируются через
транспонированную таблицу кодов (те же sparse-коды, что в эмбеддинге) и добавляется learnable
per-token bias (частотный prior, V=cfg.vocab).

- **Weight tying**: readout разделяется с basis эмбеддинга (один параметр на encode/decode).
- **Без cross-talk**: каждый сегмент отвечает за свою часть словаря.
- Параметры: token_bias 50000 (base) / 65536 (расширенный) (+ 0 для readout при tying).

### 3.1 Zeckendorf Readout (экспериментальный режим)

При `zeckendorf_readout=True` вместо PartitionedHead используется дерево Фибоначчи-Цекендорфа:
для V=50000 достаточно ~23 разрядов; предсказание идёт поразрядно с бинарной кросс-энтропией
и stateful-маскированием. По умолчанию выключен.

---

## 4. Pre-LN RMS Norm

RMSNorm без вычитания среднего: состояние делится на корень из среднего квадрата + eps и умножается
на learnable scale-вектор w ∈ ℝᴰ. Один параметр D на слой, без bias.

---

## 5. Depthwise Conv1d (k=48)

Локальный контекст на каждом из D=4096 каналов независимо: свертка с kernel_size=48, groups=D,
без bias. Каждый канал имеет собственный фильтр (4096 фильтров × 48 = 196,608 весов на слой).

- **Causal**: состояние передаётся через границы батчей (stateful буфер).
- Инициализация весов — kaiming_normal (fan_in, linear), несмотря на наличие поля conv_init_std в конфиге.
- Skip-connection: результат прибавляется к входу.

## 6. VSA Memory — 4-масштабная векторная суперпозиция

### 6.1 Механизм

VSA-память хранит суперпозицию векторов с экспоненциальным затуханием на 4 временных масштабах.
Стартовые значения τ_s = [8, 32, 128, 512], но сами масштабы **learnable**: вектор параметров
пропускается через softplus → cumsum → exp → +1, поэтому τ адаптируются в ходе обучения
(стартовые фактические значения ≈ [7, 23, 69, 207]).

Обновление памяти: новый слой = decay · прошлый слой + write_gate · вход. Сканирование по длине
выполняется ассоциативным параллельным префиксным сканом (чанками по 32 шага) для численной
стабильности; расчёт всегда ведётся в float32 независимо от dtype модели (защита долгой памяти под AMP).

### 6.2 Write gate

Write-гейт = softplus(вход·w_i + b_i + γ·||pred_error||₂): ошибка предсказания mirror
(«удивление») открывает запись. Скорость забывания модулируется per-channel (content-dependent decay):
d_mod = sigmoid(вход·w_d + b_d). В тренировочном режиме к гейту добавляется шум (усиление
исследования).

### 6.3 Чтение

Взвешенное чтение: w_mem2v · память + (1 − w_mem2v) · вход. Дополнительно вычисляется «первый момент»
(экспоненциально взвешенная статистика входа), используемый остальными модулями блока.

### 6.4 Временные константы по слоям

b_d инициализируется в диапазоне 2.0 + 3.0·(глубина/32) (L0: τ≈7, L31: τ≈150) и ограничен сверху
vsa_b_d_max=12.0 (τ≈160K). AdaptiveController динамически двигает b_d из сигнала exploration;
плавный lerp к целевому значению со скоростью 0.999 за шаг (≈1000 шагов на переход).

### 6.5 Параметры (per layer, D=4096, S=4)

w_i, b_i, w_d, b_d, w_q, w_q_leaf, w_q_ctx, w_mem2v, w_k_mu, w_q_mu, w_mu_mem (по D),
scale_w (S×D), gamma_surprisal (скаляр) ≈ 11·D + S·D + 1 ≈ 61,441 на слой.

## 7. BottleneckBind — межканальное скрещивание

### 7.1 Концепция

BottleneckBind проецирует D=4096 → K=64 через билинейное скрещивание и обратно (D → K ↔ K → D).
Это единственный cross-dimensional mixing механизм блока (вместо attention). Вход сначала нормируется
RMSNorm (bind_qk_norm), затем две K-мерные проекции перемножаются поэлементно.

### 7.2 Режимы

- **off** — диагональное билинейное произведение двух проекций без сдвигов. Ранг ≤ K.
- **shift (default)** — сумма S=4 билинейных произведений со сдвигами: вторая проекция циклически
  сдвигается на golden-ratio сдвиги (shift[s] = floor(s·K/φ) mod K). При tie_bind и S>1 включается
  multi-ocular режим: каждый сдвиг получает собственный W_out, ранг = min(S·K, D). По умолчанию
  используется golden-ratio схема.
- **cascade** — Фибоначчи-вложенные моночлены: a[1], a[2] — база, далее a[n] = пересечение
  (a[n−1]·w_u) ⊙ (a[n−2]·w_v) со сдвигом, с ремасштабированием к норме a[1]; степени моночленов
  идут по ряду Фибоначчи [1,1,2,3,5,...]; слагаемые смешиваются learnable sigmoid-весами mix_logit
  (инициализация Фибоначчи-сигмоид, независимые веса масштабов — без softmax-конкуренции).
- **gated aperture** (bind_twist_gate=True, выкл. по умолчанию) — per-token адаптивный гейт из hp,
  который модулирует вклад каждого сдвига.

### 7.3 Инициализация

- w_u, w_v: нормальное std=1.0 — критично, билинейный градиент масштабируется как std³.
- W_proj: Linear-инициализация по умолчанию (kaiming).
- W_out: Xavier gain=0.5 (не std=0.02).
- При tie_bind W_out привязывается к транспонированному W_proj через forward pre-hook (автоэнкодер) —
  применяется в режиме off/cascade; в shift/S>1 включается multi-ocular с отдельным W_out.

### 7.4 Параметры (default: shift, S=4, multi-ocular)

На слой: W_proj K·D = 262,144; W_out S·K·D = 1,048,576; w_u, w_v 2·S·K = 512; bias K = 64.
Итого ≈ 1,311,296 на слой, ×32 слоя ≈ 41.96M (≈16%).

Опции: off/S=1 с tie_bind ≈ 262K на слой; off без tie ≈ 524K на слой.

## 8. GroupedCognitiveMirror — ансамбль из 32 экспертов

### 8.1 Структура

32 эксперта, каждый работает в своём d-мерном подпространстве (Main: d = D/G = 128). Каждый эксперт:

1. Проецирует свой сегмент h[g] (d=128) в K-space hp (k измерений) через W_proj (d×k).
2. Вычисляет сигналы коррекции в K-space.
3. EMA-нормирует сигналы.
4. Смешивает их learnable сигмоидными весами с Фибоначчи-инициализацией (диагональный Jacobian,
   полный ранг, независимые градиенты).
5. Суммирует взвешенные сигналы в delta.
6. delta @ W_out (k→d) → tanh + skip_alpha·linear → умножается на gate → на exp(log_scale).

W_proj инициализируется по-экспертно ортогонально (expert_asymmetry=True); log_scale инициализируется
по-экспертно геометрически (асимметрично), что ломает симметрию старта.

### 8.2 Staircase k (по глубине)

При mirror_k_staircase=True (default) k меняется по третям глубины:

| Треть слоёв | k | d/k |
|:-----------:|:-:|:---:|
| L0–L10 | 8 | 16 |
| L11–L21 | 16 | 8 |
| L22–L31 | 32 | 4 |

Ранние (сенсорные) слои: малое k, широкое d/k — широкий K-space анализ.
Глубокие (концептуальные) слои: большое k, узкое d/k — высокая точность K-space.

### 8.3 Сигналы K-space

| Сигнал | Семантика |
|--------|-----------|
| temp_k | Отклонение от центроида памяти (что изменилось) |
| pred_error | Ошибка предсказания K-space траектории |
| smooth_k | Локальная негладкость (свёртка hp с ядром [0,1,0], causal) |
| sym_k | Билинейный временной cross-term двух последовательных hp |
| help_k (только private_mem) | Коллективная память уверенных экспертов |

Без private_mem — 4 сигнала; с private_mem — 5.

### 8.4 EMA-нормировка сигналов

RMS каждого сигнала сглаживается EMA (decay 0.999, τ≈1000 шагов) и используется для нормировки
текущего сигнала. Инициализация EMA = 1.0 (нейтральная, не подавляет старт).

### 8.5 Learnable сигнальные веса

Сигналы смешиваются через sigmoid(learnable веса) без нормировки на сумму 1. Инициализация —
Фибоначчи [1,1,2,3,5]: медленные сигналы получают больший начальный вес и больший градиент.
Энтропийная регуляризация равномерности: −H(p) с p = w/sum(w) (нормировка только для энтропии).

### 8.6 Predictive mirror (alpha)

Каждый K-space канал имеет свою временную константу τ_k в логарифмической шкале [2.0, 200.0],
α_k = exp(−1/τ_k). Предсказание pred_k = α_kg · hp_prev (per-expert, per-dim), ошибка
pred_error = hp − pred_k. alpha_diag инициализируется из τ-иерархии с per-expert сдвигом (0.85–0.99)
и может «разъезжаться» через loss alpha_novelty. Модуляция ошибки из дисперсии delta
(без learnable параметра).

### 8.7 Skip connection

Результат mirror = tanh(linear) + skip_alpha·linear. skip_alpha экспоненциально спадает по глубине
(L0 ≈ 17, L31 ≈ 0.10), обеспечивая per-dim градиент для log_scale даже при насыщении tanh.

### 8.8 K-Space gate (L2)

Gate-логиты складываются из компонент:

1. |pred_error| @ w_gate — «я не знаю этот паттерн» (L0).
2. |delta| @ w_delta_gate — «я применяю коррекцию» (Mirror).
3. grad_mod — «меня учит loss» (backprop).
4. dvar_mod — «я стабилен/нестабилен» (internal variance).
5. (только private_mem) disagreement·w_contra — «я противоречу коллективу».
6. (только private_mem) contra_expert — «эксперт систематически противоречив».

Плюс статический per-expert bias (gate_bias, linspace [−scale, scale], масштаб растёт по глубине
0.5→2.0). Итоговый gate = sigmoid(логиты) модулирует mirror: mirror = raw · gate.

grad_mod вычисляется из нормы градиента эксперта, снятой hook'ом после backward; dvar_mod — из
дисперсии delta (стабильная коррекция → gate открыт, нестабильная → закрыт).

### 8.9 Self-organizing usefulness

Каждый эксперт предсказывает свою полезность; порог — медиана по токену; usefulness =
sigmoid((логиты − порог)/температура). Температура самоорганизуется гомеостатически к целевой
энтропии. Usefulness модулирует выход MLP.

### 8.10 tie_mirror_proj

При tie_mirror_proj=True (default) W_out = транспонированный W_proj (автоэнкодер K-space),
синхронизируется forward pre-hook'ом. W_out не хранится как параметр.

### 8.11 Параметры (per layer, оценка)

| k | W_proj (G·d·k) | alpha_diag | log_scale | gate/aux | Итого (приблиз.) |
|:--:|:---------------:|:----------:|:---------:|:--------:|:-----------------:|
| 8 | 32,768 | 256 | 4,096 | ~6K | ~44K |
| 16 | 65,536 | 512 | 4,096 | ~11K | ~82K |
| 32 | 131,072 | 1,024 | 4,096 | ~21K | ~158K |

Для 32 слоёв (11×k=8 + 11×k=16 + 10×k=32) суммарно ≈ 2.4M с tie_mirror_proj (без tie — вдвое больше).
conv_smooth, сигнальные веса и прочие мелкие параметры включены в «gate/aux».

## 9. Private Memory Bank — мета-познание (L1)

*Опционально (private_mem=True; по умолчанию выключен).*

### 9.1 Концепция

Коллективная память уверенных K-space состояний экспертов. Каждый эксперт накапливает EMA своих
состояний, когда он уверен, не противоречит коллективу и не находится под социальным давлением.

### 9.2 Механизм записи

Три условия: уверенность (conf = sigmoid(−|pred_error|)), непротиворечие (contra), отсутствие
социального давления (pressure из contra_expert и isolation). Из произведения условий строится
soft-competition (T=0.5) по экспертам, взвешенное усреднение hp записывается в _private_mem с
адаптивным decay 0.990–0.999 (в зависимости от нормы памяти). Запись идёт с detach — память не
получает градиент из чтения.

### 9.3 Delayed write

Запись включается только после 5000 forward-шагов (≈1.28M токенов при batch=2, seq_len=128),
предотвращая echo-chamber collapse на старте, когда все эксперты одинаковы.

### 9.4 Механизм чтения (cross-expert attention)

Неуверенные эксперты формируют запрос q = hp·uncert; ключи — замороженная копия памяти.
Сходство q·keys проходит через **sigmoid** (не softmax): каждый эксперт получает независимый гейт
чтения 0..1 без нормировки по строке — гейты не конкурируют и могут быть одновременно нулевыми
(полный отказ от памяти). Результат масштабируется sigmoid(w_help) (init log(3) ≈ 0.75) и
доверием trust = 1 − contra.

### 9.5 help_k как 5-й сигнал

help_k добавляется к 4 базовым сигналам; все 5 смешиваются learnable сигмоидными весами с
Фибоначчи-инициализацией. Decorrelation на взвешенных сигналах даёт прямой градиент в веса.

## 10. Expert Knowledge Graph (L1.5)

*Опционально (private_mem). Граф G×G отношений между экспертами.*

- **Concept Similarity**: косинусное сходство нормализованной памяти экспертов (EMA).
- **Behavior Divergence**: 1 − косинусное сходство усреднённых за шаг hp-векторов.
- **Contradiction Graph**: думают похоже (concept_sim высоко), действуют по-разному (behavior_div
  высоко) → противоречие. contra_expert[g] = среднее по строке графа.
- **Trust Matrix**: EMA доверия (из attention), dominance[g] = сумма входящего доверия,
  isolation[g] = 1 − среднее исходящего доверия / G.

### EVA-inspired mapping

| EVA (символьный) | WideBind (K-space) |
|------------------|--------------------|
| |v1−v2|/|v1| | disagreement = |hp − help_k| / |hp| |
| 1−cos(e1,e2) | concept_sim = cos(pm[g1], pm[g2]) |
| 1−Jaccard(w1,w2) | behavior_div = 1 − cos(hp_avg[g1], hp_avg[g2]) |
| is_a цепочка | contra_graph = concept_sim · behavior_div |
| A→B→C→A | broken trust: t[i,j]·t[j,k]·(1−t[k,i]) |
| Ambiguity | contra_expert[g] = mean_j(contra_graph[g,j]) |

## 10.5 Collective Concept Layer — пер-слойный майнинг концептов

*Новое (авг. 2026). Дизайн-док: [docs/COLLECTIVE_CONCEPT_LAYER.md](docs/COLLECTIVE_CONCEPT_LAYER.md).
Прототип: `WideBand Mini/core/concept_layer.py` + симулятор `sim_collective.py` (9/9 проверок).*

Модель сама находит в K-пространстве семантические лакуны и материализует их как
прототипы-слоты коллективного банка — **без внешнего LLM**: концепт — это вектор-прототип,
не слово. Слот рождается как центр открытого кластера, формализуется EMA и либо становится
стабильным знанием, либо вытесняется.

- **Банк**: S=8 слотов m_s ∈ R^k на каждый блок, отделён от private_mem и от сигнального пути.
- **Зрелость = включение майнинга**: метрика самого слоя — mirror residual-var EMA
  (`_residual_var_ema`, `mirror.py:179`). Референс захватывается после warmup (шаг 5000);
  майнинг включается, когда resvar осел ниже `0.85·ref`. Каждый слой решает сам —
  глубокие (концептуальные) созревают раньше, сенсорные позже.
- **Запись** (no_grad): уверенные токены (`conf = sigmoid(−|pred_error|) > 0.3`) уточняют
  ближайший слот; новизнные (`d_min = 1 − max_s cos(hp, m_s) > birth_gap`) рождают новый;
  при полном банке — eviction слота с min `U_s` (занятость).
- **Две фазы**:
  - `collective_read_out=False` (**аккумуляция**, default) — слой только пишет в банк;
    **ноль обучаемых параметров**, сигнал, loss и градиенты не затрагиваются
    (проверено: loss и grad бит-в-бит идентичны модели без слоя). Наблюдение готовности
    — в логе `col: mature=… occ=… mat:[…] occ_l:[…]`.
  - `collective_read_out=True` — создаётся readout `W_o` (S·k→D); концепты входят в сигнал
    через гейт неуверенности `σ_u = sigmoid(κ·(‖pred_err‖−θ))` и гейт противоречий
    `σ_c = sigmoid(γ·(cos(Δ_c, h_ctx)−τ_c))` («розовый слон» — рождённый, но
    не подтверждённый слот — не проходит), масштаб `sigmoid(learnable)`. Признак слота —
    независимые per-slot гейты `sigmoid + норм смеси` (без softmax-конкуренции).
- **Флаги**: `collective_layer`, `collective_*` (`core/config.py`); CLI `--collective-layer`,
  `--collective-read-out`. В ноутбуке: `collective_layer=True, collective_read_out=False`.
- **Параметры**: 0 в аккумуляции; при read_out ≈ +0.03% (см. дизайн-док, раздел 6.2).

## 11. Arbiter: K-Space Gate (L2, детали)

- **grad_mod** — экспоненциально масштабированная tanh-норма градиента эксперта: loss «толкает»
  подпространство → gate открывается.
- **dvar_mod** — tanh дисперсии delta: стабильная коррекция открывает gate, нестабильная закрывает.
- **Contradiction** (private_mem) — disagreement·w_contra (w_contra init +0.01: противоречие открывает
  gate) и contra_expert (систематически противоречивый эксперт всегда открыт).

## 12. GroupedMLP — Feed-Forward

### 12.1 Архитектура

D-пространство разбивается на G=32 группы по d=128, каждая получает внутреннее расширение
d → 4d → d. По умолчанию **SwiGLU**: параллельные gate (SiLU) и up-проекции d→4d, затем down 4d→d.
Без SwiGLU — только up с SiLU. Перед входом — RMSNorm. ~79% всех параметров модели (при SwiGLU).

### 12.2 Usefulness modulation

Выход каждой группы умножается на usefulness от mirror: эксперты с высокой предсказанной
полезностью получают больший вес.

## 13. DCT Spectral — частотная фильтрация

Ортонормированный DCT-II базис (D×D) применяется к состоянию: прямое преобразование, per-frequency
масштабирование learnable lambda_k, обратное преобразование. Инициализация lambda_k: base = 0.5 +
глубина/31 (диапазон [0.5, 1.5]) с линейным спадом 1.0 → 0.5 по частотам: низкие частоты boost,
высокие cut (1/f эффект). Модель учится, какие частоты важны для данного слоя.

## 14. AdaptiveController — самоорганизующиеся гиперпараметры

Два фундаментальных сигнала управляют параметрами модели:

- **exploration** = min(1, |mirror| / λ⁻²), λ⁻² ≈ 0.296 — насколько сильно модель корректирует.
- **differentiation** = min(1, var(log_scale) / λ⁻⁴), λ⁻⁴ ≈ 0.087 — насколько специализировались эксперты.

Все границы выведены из λ_d-иерархии (d=3, λ ≈ 1.839).

| Параметр | Диапазон | От чего |
|----------|----------|---------|
| b_d (decay bias) | [2.0+3·lf, vsa_b_d_max=12] | exploration (высокая → короткая память) |
| b_i (write gate) | [−3.0, −1.5] | exploration |
| w_mem2v_scale | [λ⁻¹, 1.0] ≈ [0.544, 1.0] | differentiation |
| ema_alpha | [1−λ⁻⁶, 1−λ⁻⁸] ≈ [0.974, 0.992] | differentiation |
| noise_scale | [λ⁻⁸, λ⁻⁶] ≈ [0.0076, 0.026] | differentiation |
| tanh_bias_mod | [1.0, 1.5] | exploration |
| spectral_mod | [1±λ⁻⁴] ≈ [0.913, 1.087] | differentiation |
| pred_weight | [λ⁻⁶, λ⁻²] ≈ [0.026, 0.296] | differentiation |

Для каждого слоя используются собственные l_expl, l_diff; параметры плавно lerp-ятся к целям
(скорость 0.999). Также есть learnable per-layer сдвиг времени жизни (tau_l), двигающий b_i
в диапазоне τ −4.0 → −6.0.

## 15. MirrorLRScheduler — самоорганизующийся LR

### 15.1 Механизм

Счётчи-циклический LR: текущие значения статистик сравниваются с их EMA-базой. Для var(log_scale),
|1−α| и дисперсии gate вычисляется ratio = текущее/EMA, и множитель = 1/ratio, ограниченный [0.5, 2.0].
Сильная коррекция |mirror| даёт mag_factor = 1/ratio, ограниченный [0.2, 1.0]. Итоговый множитель —
**среднее геометрическое** трёх counter-cyclical множителей, умноженное на mag_factor, с clamp [0.05, 1.0]
и на _loss_lr_factor. Текущий LR = base_lr · множитель.

### 15.2 Компоненты

| Компонент | Что измеряет | Поведение |
|-----------|-------------|-----------|
| var_mult | var(log_scale) / EMA | специализация растёт → LR падает |
| alpha_mult | |1−α| / EMA | ошибка предсказания падает → LR падает |
| gate_mult | дисперсия gate / EMA | gate стабилизируется → LR падает |
| mag_factor | |mirror| / EMA | cap ≤ 1.0: сильная коррекция → LR не растёт |
| loss_lr_factor | отступление val_loss > 2% от лучшего | ×0.5, восстановление ×1.1 до 1.0 |

### 15.3 Warmup

λ_d-выведенный warmup: max(50, fib(10)·λ) ≈ 100 шагов. Во время warmup alpha_override плавно идёт
1.0 → 0.0 (identity → learned), температура usefulness 2.0 → 0.5 (размытая → острая конкуренция).

## 16. λ_d Hierarchy — иерархия параметров

При lambda_lr_hierarchy=True (default) группы параметров получают LR, масштабированный степенями λ_d
(λ = 1.839):

| Группа | Параметры | LR mult |
|--------|-----------|:-------:|
| embed (p=−2) | basis, mix, readout | 0.296× |
| mlp (p=−1) | MLP W_gate/W_up/W_down, bind W_proj/W_out | 0.544× |
| default (p=0) | conv, нормы, token_bias, DCT | 1.000× |

| vsa (p=−2) | b_d, b_i, scale_w (weight_decay=0) | 0.296× |

Мета-слои (mirror, gates) учатся быстрее; базовые (embed, MLP) — медленнее и стабильнее.

### 17.2 PAD/EOS masking

Токены 0 (PAD) и 2 (EOS) исключены из CE.

## 21. Статус (August 2026)

### Архитектурные изменения

- **Сигнальные веса: softmax → sigmoid + Fibonacci [1,1,2,3,5]**: диагональный Jacobian, полный ранг,
  нет перекрёстного влияния весов. Энтропийная регуляризация с нормализацией p = w/sum(w).
- **scale_w: softmax → sigmoid + Fibonacci [1,1,2,3]**; weight_decay=0 (группа vsa).
- **Decorrelaton на взвешенных сигналах**: прямой градиент в сигнальные веса.
- **Cross-expert attention: softmax → sigmoid**: независимые per-expert гейты чтения из private memory —
  гейты не конкурируют и могут быть нулевыми одновременно (полный отказ от памяти).
- **VSA-масштабы learnable** (exp-cumsum-softplus), старт ≈ [8, 32, 128, 512].
- **RoPE** в PartitionedEmbedding (theta=1e6, Qwen3-style), **SwiGLU** в GroupedMLP.
- **w_pred_scale удалён**: мёртвый параметр; модуляция ошибки — через pred_scale_mod из дисперсии delta.
- **Collective Concept Layer портирован в Main** (авг. 2026): пер-слойный майнинг концептов
  на всех 24 слоях в фазе **аккумуляции** (`collective_read_out=False`). Включение по зрелости
  каждого слоя (mirror residual-var EMA < 0.85·ref после warmup 5000). Проверено: **0 параметров**,
  loss и grad бит-в-бит идентичны baseline (инертность), дедупликация записей при
  gradient-checkpointing, готовность слоёв в логе `col:`. Этап 1 дизайн-дока (baseline 86M на T4)
  идёт параллельно; `read_out` (выпуск концептов в сигнал) — следующий шаг, только если
  аккумуляция покажет осмысленные банки.
