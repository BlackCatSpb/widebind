=== WideBind — Files for Cloud training (Сферум / Colab) ===

D=2560, G=32, d=80, K=64, mirror_k=32 (staircase 8/16/32), expand=4, 86.39M params
L=24, vocab=50000, seq_len=128, batch_size=1

=== CHANGES IN THIS VERSION ===

- W_pred (G,k,k) → alpha (G,) — scalar per expert, 1024× stronger gradient
- lo/hi k-space split removed — pred_error flows to all k dims
- G=16→32 (d/k 8:1→4:1) — 2× stronger temporal signal
- |1-alpha| logs instead of |I-diff|
- w_pred_scale_legacy REMOVED (dead param, no grad); pred_scale_mod derived from delta_var
- private_mem cross-attention: softmax → sigmoid (independent per-expert gates)
- Colab notebook: stale-code guard assert (w_pred_scale_legacy check) after model build
- scripts/expand_vocab.py: vocab expansion WITHOUT losing trained weights.
  Vocab math: max = min(C(K,S), 65536) = 65536; balance requires vocab % 16 == 0
  (so V·S/K is an integer). Use: python scripts/expand_vocab.py best.pt
  --streams wb/token_stream_*.bin --margin 5000

=== FILES REQUIRED ===

  1. core/config.py
  2. core/model.py
  3. notebooks/colab.ipynb  (or notebooks/cloud.ipynb)
  4. token_stream_*_clean.bin  (data files — MUST be present, otherwise training
     runs on random data and CE is stuck at ln(vocab)≈10.82!)

  converges slower but gates are independent. Checkpoints are compatible
  (only w_pred_scale_legacy removed).
- Verify before training: "Code version OK (no w_pred_scale_legacy)" in notebook output.
- Real data required: CE must drop below ln(vocab)=10.82 within ~200 steps.
  If CE plateaus at ~10.8 → data files missing, training is on random tokens.
